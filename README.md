# AOMS – Apartment Operations Management System

AOMS is an apartment operations management application developed using Flutter.

## Project Information

- Project: AOMS
- Client: Flutter Android Application
- Language: Dart
- Architecture: Feature-based Architecture
- State Management: Riverpod
- Navigation: GoRouter
- HTTP Client: Dio
